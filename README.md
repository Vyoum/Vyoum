### ⚡ The short version

I'm a Full Stack AI Engineer who turns messy, manual business workflows into autonomous agent systems that actually run in production — not demos, not notebooks.

- 🤝 **I start with the people, not the prompt.** I get on calls with clients, map how their team really works, and find the steps a machine should be doing.
- 🚢 **Then I ship it the same week.** Multi-agent pipelines, deterministic backends, real infra, CI/CD, live users.
- 🛡️ **I build AI you can trust with money and data.** Guardrails, confirmation gates, idempotency, and audit logs are part of the design from day one.
